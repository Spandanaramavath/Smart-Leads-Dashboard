# Smart Leads Dashboard 

## Project Overview
Smart Leads Dashboard is a MERN stack CRM application used to manage leads efficiently.

## Features
- User Authentication (JWT)
- Register & Login
- Add Leads
- Edit Leads
- Delete Leads
- Search Leads
- Status Management
- CSV Export
- MongoDB Integration

## Tech Stack
### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Installation

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run dev

## Environment Variables

Create a .env file inside backend:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
